# Contributing

This repository accepts corrections, stronger sources, original theory or practice notes, and translations.

1. Place the contribution in `A-理论层` when it explains a durable mechanism or creative judgment.
2. Place it in `B-实战层` when it provides a reusable workflow, output contract, or bounded platform method.
3. Keep every note independently understandable; do not require a private repository or personal project.
4. Distinguish stable mechanisms, source-backed interpretation, practical experience, candidate methods, and time-sensitive facts.
5. Cite primary or authoritative sources for changing product, platform, policy, price, model, or technical claims.
6. Keep private paths, personal projects, project secrets, company work, raw chats, and private retrospectives out.
7. Do not paste full third-party courses, articles, books, scripts, or transcripts.
8. Do not add images unless redistribution permission and required attribution are documented.
9. Preserve the Simplified Chinese source note when contributing a translation.
10. Run `python scripts/validate_repository.py` before opening a pull request.

Use [Discussions](https://github.com/62656456/ai-film-knowledge-base/discussions), [Issues](https://github.com/62656456/ai-film-knowledge-base/issues), or [haldissita@gmail.com](mailto:haldissita@gmail.com) to propose an improvement.
