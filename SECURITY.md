# Security policy

Do not post exposed credentials, identity-bearing private paths, unpublished company or project material, or sensitive third-party data in a public issue. Email [haldissita@gmail.com](mailto:haldissita@gmail.com) with the affected path and minimum reproduction details; redact live secrets whenever possible.

The public corpus must not contain personal data, personal projects, private retrospectives, raw chats, credentials, account data, biometric data, or private machine configuration. The one deliberate public-contact exception is the maintainer address `haldissita@gmail.com`.

Automated checks reject common secret formats, removed private layers, local images, and machine paths, but they cannot prove that every narrative sentence is safe. Human review remains required before publication.
