# 电影风格与题材视觉图鉴：看图选风格、看组合选成片方向

> **公开图像说明：** 原资料中未完成再分发权核验的图片不进入公开仓库；本页只显示已登记的原创公共图示。详见 [视觉资产登记](../../../docs/VISUAL_ASSETS.md)。

> 用途（视觉图鉴）：当你只知道“想做2D、3D、赛博朋克、某位导演/动画作者那种感觉”或任何别的风格词时，先在本卡看它最终会长什么样，再选择题材、材质、光色和组合方式。**2D、3D、赛博朋克和作者口语标签都只是入口示例，不是本卡的范围边界。**

> 本卡采用“两层结构”：前半部分是给人直接浏览和选型的风格图鉴；后半部分才解释容易混淆的术语与组合规则。图中视觉均为原创教学示意或本库已验收示意，不是影片截图；作者/工作室名称只用于知识检索，实际创作时应改写成可观察机制。

## 0. 先这样用：不要先背分类，先确定成片长相

### 0.1 六个选择槽

一套可执行的电影视觉方向，通常由六部分组成：

~~~text
成片视觉 =
制作呈现 × 造型材质 × 题材世界 × 美术源流 × 摄影质感 × 动态节奏
~~~

| 选择槽 | 你实际在决定什么 | 常见入口词 |
|---|---|---|
| 制作呈现 | 画面由真人摄影、2D、3D、定格还是混合媒介完成 | 真人、手绘2D、3D CGI、黏土定格、真人+动画 |
| 造型材质 | 线条、形体、表面和光照怎样呈现 | 赛璐璐平涂、PBR、Cel Shading、水墨、Low-poly、胶片感 |
| 题材世界 | 世界的冲突、技术、魔法、历史和生活规则 | 赛博朋克、硬科幻、武侠、哥特、成长、黑色犯罪 |
| 美术源流 | 建筑、服装、图形和文化材料来自哪里 | Art Deco、粗野主义、巴洛克、包豪斯、民间美术 |
| 摄影质感 | 镜头距离、构图、光线、色彩和介质表面 | 低调光、自然光、粉彩、高反差黑白、手持纪实 |
| 动态节奏 | 人物怎样动、摄影机怎样动、时间怎样流动 | 流畅动画、阶梯帧、长镜、跳切、慢电影、快速蒙太奇 |

输入时可以混着说，图鉴会替你拆开；交付时再把它们组合成完整句子。

### 0.2 本卡的视觉货架

| 想找什么 | 直接看哪里 |
|---|---|
| 2D、3D、赛璐璐、水墨、Low-poly、黏土等画面外观 | 第1节“制作与画面外观” |
| 科幻、赛博朋克、奇幻、武侠、恐怖、爱情、战争等题材世界 | 第2节“题材与世界观” |
| 表现主义、新现实主义、黑色电影、哥特、Art Deco等风格来源 | 第3节“影史与美术源流” |
| 电影感、胶片感、霓虹、低调光、粉彩、梦幻等摄影气质 | 第4节“摄影与影像表面” |
| “新海诚感、吉卜力感、皮克斯感、王家卫感”等大众说法 | 第5节“口语风格译码” |
| 多种风格混合后会出现什么视觉结果 | 第6节“组合成品库” |
| 只有一句模糊感觉，不知道选什么 | 第7节“按目标反查风格” |

## 1. 制作与画面外观图鉴

### 1.1 先看四种完全不同的视觉入口

#### 同一场景，只改变制作外观

| 左一 | 左二 | 右二 | 右一 |
|---|---|---|---|
| 数字2D赛璐璐式平涂 | 摄影写实/写实三维外观 | 3D Cel Shading | 黏土定格材料感 |

> 左二只能说明画面呈现出连续材质、自然接触阴影和摄影写实感，不能由单张生成图反向证明它真实使用了PBR三维管线。

**科幻题材不等于3D，赛博朋克也不等于霓虹；下面每张图只是一个可继续组合的入口。**

### 1.2 2D与平面动画外观

| 风格入口 | 一眼辨认 | 适合内容 | 常见组合与误区 |
|---|---|---|---|
| 传统手绘动画 | 逐帧线条、手工形变、背景与角色分层 | 角色表演、幻想、诗性叙事 | 可配任何题材；不等于必须使用实体赛璐璐片 |
| 传统赛璐璐外观 | 清楚描线、有限平涂色、硬边阴影、背景层次分明 | 复古动画、动作、青春、科幻 | “赛璐璐动画”是历史工艺，“赛璐璐风”只是外观 |
| 数字赛璐璐式2D | 数字线稿和平涂、色块干净、合成光更自由 | 当代动画、漫剧、动作与都市题材 | 可与3D场景、粒子和摄影光效结合 |
| 全动画 Full Animation | 动作连续、形变丰富、表演细密 | 音乐、喜剧、角色戏、动作高潮 | 是运动密度，不是单独画风 |
| 有限动画 Limited Animation | 关键姿态强、局部运动、停顿和循环明显 | 对话、喜剧、漫画感、低成本美学 | 不能把背景人物做成完全静止的纸板 |
| 矢量扁平 | 几何色块、边缘锐利、少纹理、图形层级清楚 | 科普、广告、讽刺、儿童内容 | 与包豪斯、Pop、Motion Graphics兼容 |
| 绑定/剪纸式2D | 分层肢体、关节运动、正侧面轮廓清楚 | 连续剧、喜剧、民间故事 | 数字cut-out不等于实体剪纸定格 |
| 剪影动画 | 黑色轮廓、侧向动作、负空间主导 | 童话、神话、哥特、寓言 | 需要轮廓可读，细节不能全压进黑色 |
| 转描 Rotoscope | 真人动作真实，但线条/色块跨帧变化 | 心理、身份、记忆、舞蹈 | 不是一键滤镜；须决定描摹精度与图形重构程度 |
| 水墨2D | 墨线、干湿浓淡、留白、扩散与笔势 | 武侠、神话、诗性自然、哲思 | 不是“黑白+雾”；动作路线和空间留白要共同成立 |
| 水彩动画 | 透明叠色、湿边、纸纹、颜色渗化 | 成长、爱情、记忆、四季 | 需控制跨帧沸腾和人物轮廓稳定 |
| 油画/绘画逐帧 | 厚重笔触、颜色重绘、画布物质感 | 传记、神话、记忆、艺术电影 | 不能让每帧炫技压过动作连续性 |
| 铅笔/素描 | 线稿、擦痕、留白、未完成感 | 日记、创伤、创作过程、黑白寓言 | 可与局部彩色强调组合 |
| 漫画/半色调 | 网点、速度线、分格、夸张透视、拟声图形 | 动作、青春、超级英雄、黑色喜剧 | 要先定漫画版式是否进入电影画框 |
| Pixel Art | 可见像素格、有限色板、图形化光影 | 游戏叙事、复古科幻、末日、实验短片 | 像素尺寸、色板和镜头缩放规则必须统一 |
| 动态图形 Motion Graphics | 字形、图标、几何与数据运动 | 片头、科普、散文、界面叙事 | 逻辑层级比装饰更重要 |
| 拼贴/混合平面 | 照片、纸张、绘画、纹理和档案碎片并置 | 散文电影、超现实、历史记忆、讽刺 | 每种材料应承担不同叙事功能 |

#### 同一城市黄昏，四种2D画面家族

| 左一 | 左二 | 右二 | 右一 |
|---|---|---|---|
| 数字赛璐璐式平涂 | 水彩逐帧绘画感 | 中国水墨动画语言 | 几何矢量与剪纸拼贴 |

看图重点：人物、站姿、桥栏、列车和黄昏方向基本不变；真正变化的是线条、纸张、色块、墨色密度和空间建立方式。

### 1.3 3D与计算机动画外观

| 风格入口 | 一眼辨认 | 适合内容 | 常见组合与误区 |
|---|---|---|---|
| 摄影写实3D | 真实比例、材质响应、景深与光照接近摄影 | 生物、灾难、硬科幻、虚拟人、不可拍世界 | 写实度高不等于故事可信 |
| PBR 3D | 金属/粗糙度/透射等材质规律统一，光照有物理依据 | 工程、产品、军事、建筑、太空 | PBR是着色体系，不自动等于照片写实 |
| 风格化3D | 比例、轮廓和材质被主动简化或夸张 | 家庭、喜剧、奇幻、冒险 | “卡通3D”内部仍有大量不同风格 |
| 3D Cel/Toon Shading | 三维体块配轮廓线、有限色阶和硬边阴影 | 动作、机甲、漫画、赛博朋克 | 它是三维渲染，不是传统赛璐璐工艺 |
| Painterly NPR | 三维空间保留，但表面像油画、水彩或笔刷 | 奇幻、神话、梦境、艺术动画 | 笔触要有空间和时间稳定规则 |
| Hand-painted 3D | 手绘贴图、控制性高光、弱化物理材质 | 游戏感、童话、武侠、独立动画 | 不能只贴一层“手绘纹理” |
| Low-poly | 面数精简、面片轮廓可见、几何概括明确 | 寓言、Cozy、抽象、信息可视化 | 低多边形不等于低质量或低分辨率 |
| Voxel | 体素方块构成角色与环境 | 游戏化世界、系统寓言、儿童、科幻 | 所有对象同密度会失去层级 |
| Clay-look 3D | 黏土表面、指纹、柔软边缘，但实际是CG | 家庭、喜剧、童趣、怪诞 | 应写“黏土质感3D”，不能冒充真实黏土定格 |
| 玩具/塑料3D | 注塑、软胶、搪胶、微缩产品质感 | 黑色喜剧、儿童、消费讽刺 | 材料和尺度线索必须一致 |
| 微缩/模型感3D | 浅景深、模型比例、精细小物、俯视或移轴感 | 城市、战争、世界构建、幽默 | 不等于真实微缩模型拍摄 |
| 等距/正交3D | 平行投影、信息层级清楚、空间像棋盘 | 策略、科普、系统展示、寓言 | 是投影与构图方式，不是2.5D的同义词 |
| 实时引擎视觉 | 资产、灯光和摄影机可实时调度 | 虚拟制作、机造电影、互动叙事 | 引擎是管线，不决定最终画风 |
| 动捕写实3D | 人体节奏和微表演接近真人 | 写实角色、体育、动作、数字替身 | 数据必须经过角色化和动画修整 |
| 定格感3D | 阶梯帧、替换表情、轻微材料跳变 | 手工亲密感、怪诞、喜剧 | 只能称“定格感”，除非真实逐格拍摄实体 |

#### 同一街角人物，四种3D渲染家族

| 左一 | 左二 | 右二 | 右一 |
|---|---|---|---|
| 摄影写实PBR式外观 | 圆润风格化3D | Cel Shaded 3D | Low-poly 3D |

看图重点：四栏都有三维体块，但材质连续性、角色比例、轮廓线、阴影级数和面片暴露程度完全不同。

### 1.4 实体、定格与物质动画

| 风格入口 | 一眼辨认 | 适合内容 | 关键边界 |
|---|---|---|---|
| 木偶定格 | 实体偶、关节姿态、接触阴影、材料细节 | 哥特、童话、家庭、黑色喜剧 | 实体对象被逐格拍摄 |
| 黏土定格 | 指纹、挤压、替换表情、柔软形变 | 喜剧、儿童、怪诞、寓言 | 与“黏土质感3D”分开 |
| 物件动画 | 日常物品自己行动或形成图形 | 广告、消费讽刺、实验、音乐 | 物件逻辑和比例关系要稳定 |
| 剪纸定格 | 平面纸片、关节层叠、纸纹与投影 | 民间故事、儿童、历史、寓言 | 可与剪影、布料和印刷纹样结合 |
| 沙/油画/玻璃动画 | 每帧直接改变沙、颜料或玻璃上的图像 | 记忆、神话、实验、音乐 | 前一状态常被覆盖，运动有物质连续性 |
| Pixilation真人逐格 | 真人出现不可能滑行、瞬移、机械停顿 | 荒诞、喜剧、实验 | 不是Pixel Art |
| 微缩模型实拍 | 真实模型、物理灯光、摄影景深与烟雾 | 城市、战争、灾难、科幻 | 常与CG扩展结合 |
| 机械偶/特效化妆 | 实体表演、接触、重量和现场光 | 怪兽、恐怖、生物、奇幻 | 属于现场物理效果，不是统一画风 |

#### 同一室内动作，四种实体/混合媒介

| 左一 | 左二 | 右二 | 右一 |
|---|---|---|---|
| 木偶定格 | 黏土定格 | 纸片剪纸定格 | 真人摄影+纸张/绘画混合拼贴 |

看图重点：材料不是后期滤镜；木、毛线、黏土、纸张接缝和摄影碎片分别决定不同的接触、阴影与动作想象。

### 1.5 真人、虚拟制作与混合媒介

| 组合入口 | 画面结果 | 适合内容 | 必须写清 |
|---|---|---|---|
| 纯真人实拍 | 真实演员、地点、光线和物理接触 | 剧情、纪录、现实主义、类型片 | 实景/棚拍、自然/造型、摄影基准 |
| 真人+实景特效 | 真人与爆破、机械、烟雾、化妆同场 | 战争、动作、恐怖、科幻 | 安全、尺度和连续性 |
| 真人+2D | 现实层与记忆、想象、图形或角色层并置 | 青春、散文、喜剧、音乐 | 2D承担哪一层现实 |
| 真人+3D | 数字角色、环境或物体进入摄影空间 | 奇幻、科幻、灾难、广告 | 光源、比例、接触、镜头匹配 |
| 2D+3D | 2D角色/特效与3D空间互补 | 动作、机甲、漫画、世界构建 | 各媒介的主次和跨镜稳定 |
| 定格+CG | 保留实体材料，同时修补绑定、表情、环境或特效 | 高品质定格、奇幻、怪诞 | 哪些是真的实体，哪些是数字辅助 |
| 虚拟制作 | LED/实时场景与现场演员、摄影机协同 | 太空、驾驶、宏大环境、复杂天候 | 是生产流程，不是固定风格 |
| 档案+图形+重演 | 历史证据、统计、地图和表演并置 | 纪录、历史、调查、散文 | 证据层级和来源必须可追溯 |

## 2. 题材与世界观视觉图鉴

### 2.1 科幻、未来与“Punk”家族

| 题材/世界 | 核心冲突 | 常见视觉证据 | 不能缩成 |
|---|---|---|---|
| 科幻 Science Fiction | 科学、技术或社会假设改变现实规则 | 新技术、制度、环境和人的后果 | 银色飞船和蓝光 |
| 硬科幻 | 工程、物理、生存约束与因果可信 | 功能设备、程序、后勤、真实尺度 | 冷灰金属 |
| 近未来 | 现实技术和制度向前一步 | 熟悉城市、渐进式设备、现实服装 | 满城悬浮车 |
| 太空歌剧 | 星系尺度、阵营、冒险和宏大情感 | 巨构、舰队、异星文明、仪式化空间 | 只有大飞船 |
| 军事科幻 | 组织、指挥、后勤、技术和战争伦理 | 功能装备、通信链、补给与损耗 | 战术UI贴纸 |
| 机甲 | 人与巨型机械、国家/组织和身体关系 | 驾驶结构、维修、尺度、战斗职责 | 只展示机器人造型 |
| 赛博朋克 | 高技术与低生活、企业/国家权力、身体和身份 | 密集基础设施、监控、义体、阶层空间 | 紫粉霓虹夜城 |
| 后赛博朋克 | 技术已日常化，人物在复杂制度中生活与反抗 | 普及式技术、平台治理、混合阶层 | 把赛博朋克调亮 |
| Solarpunk | 可持续技术、共同体、修复与社会正义 | 能源、水、食物、公共空间、劳动协作 | 绿植玻璃楼 |
| Steampunk | 蒸汽技术和替代历史塑造社会 | 锅炉、机械传动、时代服装、帝国/阶级 | 黄铜齿轮堆砌 |
| Dieselpunk | 内燃机、两战间至战后机器文化与替代历史 | 柴油机械、航空、Art Deco、宣传美术 | 飞机+烟雾 |
| Atompunk | 原子时代、太空竞赛和冷战未来想象 | Googie、原子图形、流线家电、早期火箭 | 复古家具 |
| Raypunk/Pulp SF | 纸浆科幻、射线枪、奇异行星和装饰性未来 | 鲜艳异星、奇想飞船、怪诞科学 | 随意复古太空 |
| Biopunk | 基因、生物工程、身体所有权和生命产业 | 湿性实验室、组织生长、医疗企业系统 | 到处长肉 |
| Nanopunk | 纳米技术改变材料、身体和监控 | 自组装、微尺度变化、智能材料 | 闪亮粒子 |
| 反乌托邦 | 制度以秩序、安全或效率压迫个体 | 统一空间、监控、配给、身份等级 | 全片灰色 |
| 乌托邦/理想社会 | 更好制度的运行与代价 | 公共服务、资源分配、参与式空间 | 无冲突宣传片 |
| 复古未来主义 | 过去时代对未来的想象重新出现 | 老材料、旧图形、时代技术逻辑 | 任何复古+科技 |
| 气候科幻 | 气候变化引发迁徙、资源、政治和生态后果 | 基础设施、极端天气、土地变化、适应劳动 | 单一灾难奇观 |
| 后末日 | 文明崩解后的生存、记忆和新秩序 | 废墟再利用、资源稀缺、生态变化 | 生锈废车 |
| 外星接触 | 他者、沟通、知识与人类位置 | 语言、尺度、生态、非人类行为 | 怪物入侵 |

#### 同一城市街区，四种未来世界不是“换配色”

| 左一 | 左二 | 右二 | 右一 |

## 6. 风格组合成品库

### 6.1 组合不是“把名词全塞进去”，而是让每个词负责一件事

~~~text
示例：
3D CGI（制作）
+ Cel Shading（渲染）
+ 赛博朋克（世界）
+ Neo-noir（类型/道德）
+ Art Deco与Brutalism（美术）
+ 低调功能光（摄影）
+ 阶梯帧动作（动态）
= 三维空间中的图形化赛博黑色电影
~~~

同一组合内：

1. 不同层通常可以直接叠加；
2. 同一层若出现两种风格，必须分主次、地区、阵营、时间或现实层；
3. “科幻+赛博朋克”是父类与子类，不是两个独立滤镜；
4. 每个词必须改变形体、材质、空间、光色、动作或声音中的至少一项；
5. 单个镜头只继承当前画面真正需要的部分。

#### 四套完整组合A：同一“入口交换物件”动作

| 左一 | 左二 | 右二 | 右一 |
|---|---|---|---|
| 3D Cel Shading + 赛博朋克 + Neo-noir + Art Deco/Brutalism | 2D水彩 + Solarpunk + 青春爱情 + 高调天气光 | 真人写实 + 硬科幻 + Brutalism + 纪录观察 | 木偶定格 + Gothic Romance + 德国表现主义 + 低调光 |

同一个基本动作被四套组合重建后，人物、建筑、材料、光源、世界制度和情绪关系都随之改变；这才是“组合后的视觉效果”。

| 怀旧、记忆、时间柔软 | 胶片颗粒/暖记忆 + 柔焦 + 空镜/慢镜 + 物件和声音触发 |
| 暴烈、机械、旧工业未来 | Dieselpunk + Art Deco/Constructivism + 微缩/实拍质感 + 战争Noir |
| 实验、像梦和论文同时发生 | 真人/档案 + 2D拼贴 + 超现实 + Essay Film + 声音拼贴 |

## 8. 高频易混概念：只在需要时查

| 容易混淆 | 正确理解 |
|---|---|
| 2D / 3D | 描述资产和空间的制作结构，不决定题材和情绪 |
| 3D CGI / 立体电影 | 前者是三维资产制作，后者是左右眼视差放映 |
| 2.5D | 非统一术语，必须改写为具体结构，如“六层2D景片置于3D摄影机空间” |
| 赛璐璐动画 / 赛璐璐风 | 前者原指透明片分层拍摄工艺；后者可能只指平涂和硬阴影 |
| Cel Animation / Cel Shading | 一个是历史动画工艺，一个是常用于3D的非真实感渲染 |
| PBR / 写实 | PBR是材质和光照模型；比例、镜头、动画和合成不可信时仍不写实 |
| NPR / Cel Shading | NPR是非照片写实的大类，Cel Shading只是其中一支 |
| Stop Motion / 定格感 | 前者真实逐格拍实体；后者可由CG模拟阶梯帧和材料跳变 |
| Low-poly / 低画质 | Low-poly是几何造型策略，可用高分辨率高质量渲染 |
| Pixel Art / Pixilation | 前者是像素图形；后者是真人逐格表演 |
| Anime / 单一画风 | Anime是广泛产业与文化标签，内部包含多种线条、上色、动作和题材 |
| 国漫 / 单一画风 | 国漫可包含2D、3D、水墨、剪纸、写实与卡通等多种方向 |
| 科幻 / 赛博朋克 | 科幻是父类型，赛博朋克是关注高技术、权力、身体和失序社会的分支 |
| 赛博朋克 / 霓虹夜城 | 霓虹只是可能的光源结果；没有技术权力与阶层关系，可能只是未来夜景 |
| Solarpunk / 绿植建筑 | Solarpunk还需能源、共同体、劳动、修复和社会正义机制 |
| Steampunk / Dieselpunk / Atompunk | 分别围绕蒸汽时代、内燃机/两战机器文化、原子时代未来想象 |
| Film Noir / Neo-noir | Noir主要指历史周期和传统；Neo-noir把其主题/形式移入后来社会 |
| 哥特 / 恐怖 | 哥特可用于爱情、历史和奇幻，不必一定产生恐怖 |
| 电影感 / 一个滤镜 | 电影感来自景别、构图、光源、色彩、材质、运动、声音和叙事关系 |
| 导演名 / 成品参数 | 导演名只作检索入口，必须翻译为可观察机制 |
| 4K、8K、24fps / 风格 | 它们是规格和采样参数，不是完整视觉风格 |

## 9. 与知识库其他卡片怎样分工

- 本卡负责：看图选风格、辨认风格、组合风格、形成一套成片方向。
- A2组《类型片语法》负责：类型为什么成立、观众期待和叙事机制。
- A2组《导演与摄影指导风格》负责：作者和摄影指导的完整机制与案例。
- A2组《镜头语言机制与摄影机行为》负责：景别、角度、机位、运镜、焦段和时间采样。
- A1摄影组负责：光线、色彩、构图、景深和摄影参数的精确落地。
- B2提示词工程组负责：把已选风格翻译成单镜头可观察提示；单镜只写画面真实存在的部分。
