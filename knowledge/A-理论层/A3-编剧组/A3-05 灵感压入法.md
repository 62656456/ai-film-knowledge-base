# 灵感压入法
> 用途（速查）：拿到一个词/画面/概念，需要快速把它压成一个可写的故事种子。

## 压入公式

**一人 → 一个当下目标 → 一个阻碍 → 一个必须现在行动的理由**

```mermaid
flowchart LR
    I["灵感：画面／话／物件／设定"] --> P["一人"] --> G["当下目标"] --> O["具体阻碍"] --> N["必须现在行动"] --> S["可写的第一场戏"]
```

任何灵感，先问四问，再说"然后呢"。

## 四种灵感来源处理

| 灵感来源 | 处理方式 | 示例 |
|---------|---------|------|
| 一个画面 | 谁在看？看到了什么不该看的？ | 雨夜红伞 → 伞下藏着谁不该被看见的东西 |
| 一句话 | 谁说给谁听？对方信不信？ | "我们扯平了" → 说话的人烧掉了对账的唯一证据 |
| 一个物件 | 谁需要它？为什么不能直接拿到？ | 一把钥匙 → 钥匙在死者胃里，必须解剖 |
| 一个设定 | 在这个设定里谁最难受？ | 时间循环 → 每次循环后女儿都会忘记昨天喊过他爸爸 |

## 灵感扩展检查

| ✅ 有效 | ❌ 无效 |
|---------|--------|
| 能立刻产生第一场戏 | 还要继续补充世界观才能写 |
| 有一个必须解决的当下问题 | 只有氛围和设定 |
| 有一个人物已经在处境里 | 人物还没有，需要从世界观里找 |

## 常见错误

- **扩成世界观百科**：不要从"时间循环"开始描述机制 → 直接从"他第三次回到早上七点，女儿又不认识他了"开始
- **泛化成氛围**：不要从"雨夜"开始渲染 → 从"他蹲下来看轮胎印，印子里有血"开始
