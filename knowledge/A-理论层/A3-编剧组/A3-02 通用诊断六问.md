# 通用诊断六问
> 用途（速查）：拿到任何一段文本（梗概/场景/对白/分场），先用六问判定它有没有戏剧功能。不先评价"好不好"，先问"有没有"。

## 六问清单

```mermaid
flowchart LR
    T["待诊断场景"] --> W["欲望"] --> O["阻碍"] --> C["选择"] --> I["信息增量"] --> E["情绪载体"] --> R["后果"]
    R --> P["戏剧功能完整"]
```

| # | 问题 | 不通过的标志 |
|---|------|------------|
| 1 | 有没有欲望？ | 角色在被动经历，没有主动目标 |
| 2 | 有没有阻碍？ | 一切顺利，没有阻力 |
| 3 | 有没有选择？ | 只有一条路可走，或者选项没有冲突 |
| 4 | 有没有信息增量？ | 看完这场和看之前没有区别 |
| 5 | 有没有情绪载体？ | 情绪只靠形容词/旁白，没有动作或物件承载 |
| 6 | 有没有后果？ | 选择做了，什么都没改变 |

## 判定规则

- **六问全无** → 不是剧本，是设定说明书 → 重写
- **有3-4项** → 方向对，需补足短板
- **六问全有** → 戏剧功能完整，可进入下一步

## 常见"不是问题"的伪装

不要被这些说法骗过去：
- "人物设定很丰富" → 没用，要有当下的欲望和选择
- "世界观很完整" → 没用，要有一个角色在世界观里被逼到做选择
- "情绪很饱满" → 没用，要看到是什么动作/物件让情绪可见
