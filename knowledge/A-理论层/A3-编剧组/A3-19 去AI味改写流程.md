# 去AI味改写流程
> 用途（速查）：用 A3-18 诊断出AI味后，按三删三补流程改写文本。

## 三删

```mermaid
flowchart LR
    O["原文"] --> D["六病诊断"] --> X["三删｜大词／解释／总结"] --> A["三补｜不完美反应／生活摩擦／留白"] --> C["动作可见性检查"] --> R["改写稿"]
```

| 删什么 | 如何识别 | 删完后 |
|--------|---------|--------|
| 删抽象大词 | "命运""人生""真正的"等词出现 → 整句删 | 用具体动作重建意思 |
| 删解释性心理 | "因为他童年/因为他性格…" → 整段删 | 让行为本身说话，不解释为什么 |
| 删主题总结 | "我终于明白…""原来…" → 整句删 | 用最后一刻的选择代替总结 |

## 三补

| 补什么 | 如何操作 | 示例 |
|--------|---------|------|
| 补不完美反应 | 给角色加嘴硬/迟疑/打岔/做错小事/把话咽回去 | 删掉"他很难过"，补上"他把手机翻过来扣桌上" |
| 补生活摩擦 | 插入一件和剧情无关的小事 | 角色在关键时刻找不到钥匙，蹲下来摸鞋底 |
| 补留白 | 让观众自己补全情绪 | 不说"她原谅他了"，只拍她把他的杯子重新倒满水 |

## 改写流程

```
原文 → 六病诊断（A3-18） → 圈出病句 → 三删 → 三补 → 对照检查
```

## 对照检查清单

| 检查项 | 改前 | 改后 |
|--------|------|------|
| 还有"感受到/意识到/明白了"吗？ | | |
| 还有角色替观众总结吗？ | | |
| 还有"因为他…"的解释吗？ | | |
| 有没有至少一个不完美反应？ | | |
| 有没有和主线无关的生活细节？ | | |
| 删掉所有对白，还能看懂吗？ | | |

## 警告

不要一味删短。改写目标是"变具体"，不是"变短"。有的场景删完反而空了，需要补具体动作而不是删了就走。真人文本常常不是更华丽，而是更有毛边。
