# 拉片转创作：只搬方法不搬剧情
> 用途（速查）：拿到拉片蒸馏结果后，将其转化为可用于原创剧本的创作方案。

## 转化铁律

**只复用方法，不复用原作角色、情节、台词和专有设定。**

```mermaid
flowchart LR
    S["原作具体场景"] --> M["剥离角色／情节／台词／设定"] --> R["保留可复用机制"] --> N["生成原创人物与处境"] --> T["用新样本验证"] --> O["进入对应知识卡"]
```

## 转化模板

```
输入：拉片蒸馏结果（来自 A3-20 拉片与技法蒸馏的技法卡输出）

输出以下七项：
1. 可借用技法（剥离原作的创作规则，每条标注适用题材）
2. 原创故事种子（用技法框架生成新故事，与原作完全不同）
3. 主角欲望（可拍的、具体的当下目标）
4. 关键阻碍（谁或什么挡住他）
5. 对白策略（这场新人物的对白怎么绕）
6. 去AI味规则（这个技法对应的去AI味重点）
7. 分镜前置重点（这个技法的视觉化要点 → 接 A3-22 剧本转分镜前置分析）
```

## 转化示例

| 拉片发现 | 错误转化 | 正确转化 |
|---------|---------|---------|
| 《教父》开场拒绝戏的潜台词结构 | 写一个类似的黑帮老大场景 | "所求者暴露弱点，被求者掌控节奏"→ 适用任何权力不对等对话 |
| 《寄生虫》的半地下室窗景 | 也写一个住半地下室的家庭 | "日常物件（窗户）持续提醒人物的阶层位置"→ 适用任何阶级题材 |
| 《婚姻故事》的争吵递进 | 写一对夫妻吵架 | "从具体事（接孩子）→翻旧账→碰红线→无法挽回"的四级递进结构 |

## 下一步

转化完成 → 写入创作素材库（个人积累的技法卡集合）对应创作模块 → 触发 A3-05 灵感压入法生成新故事。
