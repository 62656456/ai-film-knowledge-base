# 顶光提示词参照表
> 用途（速查）：顶光8种场景效果的英文关键词速查，直接复制粘贴到提示词的光线栏位。

## 使用方式

确定场景类型后，从下方选取对应的英文关键词块，拼接到提示词的 Lighting 部分。可叠加环境修饰词增强效果。

## 8种顶光场景关键词块

### 1. 正午沙漠（强烈/刺眼）
```
harsh overhead sunlight, midday desert light, extreme top light, 
deep shadows under eyes and chin, high contrast, no fill light, 
sun directly overhead at zenith, scorching bright highlights
```
适用：荒野独行、末日求生、沙漠作战、热浪场景

### 2. 审讯室（冷酷/压迫）
```
interrogation room overhead light, single bare bulb from above, 
stark top-down illumination, hard shadows, cold white fluorescent, 
prison cell lighting, harsh ceiling light, oppressive atmosphere
```
适用：刑侦、审讯、禁闭、高压对话

### 3. 舞台聚光灯（戏剧/聚焦）
```
theatrical spotlight from above, stage overhead spotlight, 
dramatic top-down pool of light, dark surroundings, single beam, 
performance lighting, spotlight cone from ceiling
```
适用：表演、演说、独白、魔术、舞台剧

### 4. 神殿/教堂（神圣/庄严）
```
divine light from above, god rays streaming from above, 
cathedral ceiling light, sacred overhead illumination, 
dust particles in light beams, holy atmosphere, ethereal glow from top
```
适用：宗教、祈祷、神殿、史诗降临

### 5. 实验室/手术室（冷白/无菌）
```
surgical overhead light, clinical top lighting, bright fluorescent from above, 
sterile white illumination, laboratory ceiling lights, 
clean cold light, medical examination lighting
```
适用：科研、手术、实验室、科幻实验

### 6. 电梯/楼道（昏暗/悬疑）
```
dim overhead light, flickering ceiling light, narrow beam from above, 
dark stairwell lighting, faint glow from light fixture above, 
unstable illumination, eerie top light
```
适用：恐怖、追逐、悬疑、午夜走廊

### 7. 阳光穿透树冠（自然/斑驳）
```
dappled overhead sunlight, light filtering through tree canopy, 
sunlight through leaves from above, spotted light and shadow, 
forest canopy lighting, sunbeams from treetops
```
适用：森林、丛林、公园、户外露营

### 8. 霓虹灯顶光（赛博/迷幻）
```
neon overhead glow, colored top light from neon signs, 
cyberpunk ceiling illumination, vibrant colored light from above, 
neon tube light shining downward, electric colored overhead light
```
适用：赛博朋克、夜店、游戏厅、未来城市
