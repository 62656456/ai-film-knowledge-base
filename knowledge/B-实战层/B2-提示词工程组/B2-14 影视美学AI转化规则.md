# 影视美学AI转化规则
> 用途（规则）：定义影视美学知识如何转成 AI 分镜、图片与视频提示词，并提供有效词/无效词及反面案例。写提示词前查规则，写完查反面案例；与 B2-15《提示词可复用表达库》分工：本卡=转化规则，B2-15=可直接调用的成品模板。

---

## 一、核心原则：从"形容词"到"参数"

### 问题诊断

AI 生成中最常见的错误是用空泛形容词描述画面：

| ❌ 无效表达 | 为什么无效 | ✅ 有效表达 | 为什么有效 |
|-----------|---------|-----------|---------|
| 电影感 | 任何画面都可以说"电影感" | Arri Alexa 拍摄，2.39:1 宽银幕，低饱和调色 | 指定了具体器材、画幅、色彩策略 |
| 氛围感 | 不指向任何可执行参数 | 低调光，侧光 45°，阴影占画面 60% | 指定了光比、光位、阴影比例 |
| 高级感 | 纯主观判断，无法执行 | 50mm 定焦，f/2.8 浅景深，主体居中，负空间占左侧 1/3 | 指定了焦段、光圈、构图、空间分配 |
| 很有故事感 | AI 无法理解"故事" | 推镜从远景到中近景，3 秒，人物背影逐渐清晰 | 指定了运镜方向、起止景别、时长、动作 |
| 史诗感 | 无法转化为画面参数 | 24mm 广角，低机位仰拍，人物占画面 1/8，逆光轮廓 | 指定了焦段、机位、人物比例、光位 |

### 转化铁律

1. **每个美学决策必须落到可执行参数**：焦段、光圈、机位高度、角度、光位、光比、色温、饱和度、画幅比
2. **运镜必须指定方向+速度+起止**：推/拉/摇/移+快/慢/匀+从X景别到Y景别
3. **情绪必须通过技术参数间接表达**：不说"孤独"，说"人物占画面 1/8，周围大面积负空间，冷蓝色调，浅景深虚化背景"
4. **案例参考必须具体到镜头**：不说"像诺兰风格"，说"IMAX 70mm 胶片质感，广角低角度，人物在巨构空间中显得渺小，参考《敦刻尔克》海滩段落"

## 二、分镜转化规则

### 分镜描述的标准结构

```text
【镜号】镜1
【景别】中近景（MCU）
【机位】平视，齐肩高度
【焦段】50mm
【运镜】固定
【光影】侧光 45°，低调光，阴影占画面右侧 60%
【色彩】低饱和，冷蓝色调，肤色保留暖色
【构图】人物居右 1/3，左侧负空间
【动作】角色缓缓抬头，目光从地面移向窗外
【情绪意图】从压抑转向一线希望
【时长】4秒
```

### 分镜写法规则

| 维度 | 规则 | 示例 |
|------|------|------|
| 景别 | 用标准术语，标注英文缩写 | 大远景（EWS）/ 中近景（MCU）/ 大特写（ECU） |
| 机位 | 标注角度+高度+与主体关系 | 仰拍 15°，低机位（膝盖高度），过肩 |
| 焦段 | 标注具体mm值+镜头类型 | 24mm 广角 / 85mm 长焦 / 50mm 标准 |
| 运镜 | 标注运动类型+方向+速度+起止 | 推镜，匀速，从中景推至近景，3秒 |
| 光影 | 标注光位+光质+光比+影调 | 侧前光 45°，硬光，光比 8:1，低调光 |
| 色彩 | 标注主色调+饱和度+对比度 | 橙黄主色，高饱和，高对比 |
| 构图 | 标注构图法+主体位置+空间分配 | 三分法，主体居右 1/3，左侧负空间 |
| 情绪 | 通过技术参数间接表达，不直接说情绪 | （不说"孤独"）人物占画面 1/8，冷蓝色调，浅景深 |

## 三、图片提示词转化规则

### 图片提示词标准结构

```text
[主体描述], [景别], [机位与角度], [焦段], [光影], [色彩], [构图], [风格参照], [技术参数]
```

### 有效词与无效词对照

#### 景别

| ✅ 有效词 | ❌ 无效词 |
|----------|---------|
| extreme wide shot, EWS | big scene, grand view |
| close-up, CU | zoom in, detail view |
| medium shot, MS | normal shot, regular framing |
| bird's-eye view | top view, looking down |
| low angle shot | from below, upward angle |
| Dutch angle | tilted, askew |

#### 光影

| ✅ 有效词 | ❌ 无效词 |
|----------|---------|
| low-key lighting, chiaroscuro | dramatic lighting, moody light |
| golden hour, magic hour | beautiful sunset light |
| practical lighting, in-scene light source | natural looking light |
| rim light, backlight | glowing edges, halo effect |
| Rembrandt lighting, triangle light | artistic portrait light |
| hard light, deep shadows | contrasty, dark and light |

#### 色彩

| ✅ 有效词 | ❌ 无效词 |
|----------|---------|
| teal and orange color grade | vibrant colors, pop of color |
| desaturated, low saturation | muted tones, subtle colors |
| monochromatic blue palette | blue theme, blue atmosphere |
| complementary color contrast | colorful, vivid |
| bleach bypass, high contrast low saturation | film look, vintage feel |

#### 运镜（视频用）

| ✅ 有效词 | ❌ 无效词 |
|----------|---------|
| dolly in, slow push in | moving forward, coming closer |
| tracking shot, lateral movement | following shot, side movement |
| whip pan | fast turn, quick swipe |
| dolly zoom, Vertigo effect | weird zoom, disorienting effect |
| Steadicam, smooth tracking | smooth shot, steady movement |
| handheld, documentary style | shaky cam, raw footage |

### 风格参照有效写法

```text
# 有效：引用具体DP/影片+具体技术
"in the style of Roger Deakins, practical lighting, Arri Alexa"
"cinematography by Greig Fraser, desert landscape, IMAX"
"Blade Runner 2049 color palette, orange dust haze"

# 无效：引用模糊概念
"cinematic style"
"Hollywood look"
"award-winning cinematography"
```

## 四、视频提示词转化规则

### 视频提示词的额外维度

图片提示词只需描述静态画面，视频提示词还必须指定：

| 维度 | 规则 | 示例 |
|------|------|------|
| 运镜轨迹 | 起始位置→结束位置+运动路径 | 从远景匀速推至中近景，摄影机沿Z轴直线前进 |
| 运镜速度 | 匀速/加速/减速+大致时长 | 匀速推进，4秒，从中景到近景 |
| 主体运动 | 主体做什么+方向+速度 | 人物从画面右侧缓慢走向左侧，步伐沉重 |
| 焦点变化 | 如果有移焦，指定从什么到什么 | 焦点从前景的手部转移到背景的人物面部 |
| 时间效果 | 如果有慢动作/延时，指定倍率 | 120fps 拍摄，播放为 1/4 速慢动作 |
| 转场 | 如果有转场，指定类型 | 甩镜转场：快速向右甩镜，接下一镜头 |

### 视频提示词标准结构

```text
[运镜描述], [主体动作], [景别变化], [光影], [色彩], [构图], [时长], [风格参照]
```

### 平台适配建议

> ⚠️ 平台特性为截至 2026-07 的经验归纳，随各平台版本迭代会变化，待真实 API 实测校准。

| 平台 | 特点 | 提示词建议 |
|------|------|----------|
| 即梦/Seedance | 中文友好，支持运镜关键词 | 运镜用中文术语（推镜/拉镜/横移/环绕），光影用中文+英文 |
| 可灵 Kling | 中文为主，运镜理解较好 | 运镜描述详细，指定起止景别和速度 |
| Runway Gen-3 | 英文为主，运镜理解强 | 用英文运镜术语，指定 camera movement |
| Midjourney（图片） | 英文为主，风格化强 | 用英文术语，指定 lens/light/color/composition |
| Stable Diffusion（图片） | 英文，参数化强 | 用英文术语+权重，指定具体参数 |

## 五、避免"假电影感"的检查清单

### 什么是"假电影感"

AI 生成中最常见的失败模式：画面看起来"像电影截图"，但经不起专业审视——光影没有来源、构图没有动机、色彩没有叙事理由。

### 检查清单

| 检查项 | 合格标准 | 不合格表现 |
|--------|---------|----------|
| 光源可信度 | 画面中能看到光源来源（窗、灯、屏幕）或风格理由 | 光从莫名其妙的方向来，没有物理依据 |
| 景别动机 | 景别选择有叙事理由（情绪积累→特写） | 随意切景别，没有情绪递进 |
| 构图动机 | 主体位置有构图理由（权力关系→偏移构图） | 居中就完事，不考虑空间关系 |
| 色彩叙事 | 色彩选择有情绪/叙事理由（疏离→冷蓝） | 随便加个滤镜，色彩和情绪无关 |
| 运镜动机 | 运镜有叙事理由（逼近→推镜） | 运镜只是为了"动起来" |
| 景深控制 | 景深有叙事理由（隔离→浅景深） | 全部浅景深或全部深焦 |
| 人物比例 | 人物在画面中的大小有叙事理由 | 不考虑人物与环境的关系 |

## 六、反面错误案例库

### 错误1：堆砌形容词

```text
❌ "电影感画面，氛围感十足，高级感光影，故事感构图，史诗感场景"

✅ "24mm 广角镜头，低机位仰拍 15°，人物占画面 1/8 居中，背景为巨型工业建筑，
   逆光勾勒轮廓，前景有模糊管道遮挡，低饱和冷蓝色调，2.39:1 宽银幕画幅"
```

### 错误2：引用空泛风格

```text
❌ "诺兰风格，大片质感"

✅ "IMAX 70mm 胶片质感，广角低角度，人物在巨构空间中显得渺小，
   自然光倾向，冷峻低饱和色调，参考《敦刻尔克》海滩段落"
```

### 错误3：运镜描述模糊

```text
❌ "镜头慢慢移动，有运动感"

✅ "推镜，匀速，从中景推至中近景，3秒，摄影机沿Z轴直线前进，
   焦点固定在人物面部"
```

### 错误4：色彩描述不可执行

```text
❌ "色彩很有情绪，冷暖对比"

✅ "主体保留暖肤色（约3200K），背景推向青蓝色（约5600K），
   整体低饱和（-30%），高对比度，参考 teal and orange 调色"
```

### 错误5：光影没有来源

```text
❌ "侧光照亮人物，很有戏剧性"

✅ "侧光来自画面左侧的窗户，硬光，光比约 4:1，
   人物面部左半亮右半暗，阴影占画面右侧 50%"
```

### 错误6：忽视景别动机

```text
❌ "先拍远景，再拍特写"

✅ "镜1：大远景建立场景，人物占画面 1/10，4秒
   镜2：中景交代人物与环境关系，2秒
   镜3：中近景观察人物表情变化，情绪积累后切入
   镜4：特写捕捉决定瞬间的微表情，2秒"
```

### 错误7：视频提示词缺少运镜

```text
❌ "一个女孩站在雨中，城市霓虹灯，赛博朋克风格"

✅ "手持跟拍，从背后跟随女孩在雨夜街道行走，中景，
   霓虹灯逆光勾勒轮廓，湿地面反射彩色光，低饱和青蓝主色，
   持续4秒，镜头轻微晃动制造临场感"
```
