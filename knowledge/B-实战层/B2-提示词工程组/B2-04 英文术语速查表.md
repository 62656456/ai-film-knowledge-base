> 用途（速查）：Camera/Lighting/Style/Df 中英文对照速查，写提示词时快速查找正确英文术语。

## 使用方式

按类别查找需要的术语，直接复制英文关键词填入七字段对应位置。每个术语附中文释义和使用场景说明。

## Camera 运镜/景别

### 景别 Shot Size

| 英文 | 中文 | 说明 |
|------|------|------|
| extreme wide shot | 大远景 | 交代大环境，人物很小 |
| wide shot | 全景 | 人物全身+环境 |
| full shot | 全身镜头 | 人物刚好全身入画 |
| medium wide shot | 中远景 | 人物膝盖以上 |
| medium shot | 中景 | 人物腰部以上，最通用 |
| medium close-up | 中近景 | 人物肩/胸以上 |
| close-up | 特写 | 面部充满画面 |
| extreme close-up | 大特写 | 眼睛/嘴唇/细节 |
| over-the-shoulder | 过肩镜头 | 从A肩后拍B，对话常用 |
| point of view | 主观镜头 | 模拟角色视角 |
| two shot | 双人镜头 | 两个人物同框 |

### 镜头运动 Camera Movement

| 英文 | 中文 | 说明 |
|------|------|------|
| static / fixed | 固定镜头 | 不动 |
| pan left / pan right | 左摇/右摇 | 水平旋转 |
| tilt up / tilt down | 上摇/下摇 | 垂直旋转 |
| dolly in / push in | 推镜头 | 向前推进 |
| dolly out / pull out | 拉镜头 | 向后退 |
| tracking shot | 跟移镜头 | 与主体平行移动 |
| crane shot | 摇臂镜头 | 上下升降 |
| handheld | 手持镜头 | 有轻微抖动感 |
| steadicam | 斯坦尼康 | 平滑移动无抖动 |
| aerial / drone shot | 航拍/无人机 | 空中俯瞰 |
| zoom in / zoom out | 变焦推/拉 | 焦距变化 |
| rack focus | 焦点转换 | 焦点从前景切到背景或反之 |
| slow motion | 慢动作 | 升格拍摄 |
| whip pan | 快速甩镜 | 快速水平摇摄，用于转场 |
| orbit / arc shot | 环绕镜头 | 绕主体旋转 |

### 镜头角度 Camera Angle

| 英文 | 中文 | 效果 |
|------|------|------|
| eye level | 平视 | 客观中性 |
| low angle | 仰拍 | 威严/英雄/压迫 |
| high angle | 俯拍 | 弱化/被审视 |
| bird's eye view | 鸟瞰 | 上帝视角/全局 |
| worm's eye view | 蚁视 | 极端仰拍/戏剧化 |

## Df (Depth of Field / Focus) 景深与对焦

| 英文 | 中文 | 使用场景 |
|------|------|---------|
| shallow depth of field | 浅景深 | 肖像/突出主体/虚化背景 |
| deep depth of field | 深景深 | 风景/建筑/全景清晰 |
| bokeh | 散景 | 背景光斑虚化效果 |
| sharp focus | 清晰对焦 | 主体明确锐利 |
| soft focus | 软对焦 | 梦幻/柔美 |
| selective focus | 选择性对焦 | 只对画面某一部分清晰 |
| tilt-shift focus | 移轴对焦 | 微缩模型效果 |
| foreground blur | 前景虚化 | 增加层次感 |
| background blur | 背景虚化 | 突出前景主体 |
| f/1.4 / f/1.8 / f/2.8 | 光圈值 | f值越小景深越浅虚化越强 |
| f/8 / f/11 / f/16 | 光圈值 | f值越大景深越深全景越清晰 |
| 35mm / 50mm / 85mm / 135mm | 焦距 | 85mm-135mm适合人像虚化 |
| 24mm / 16mm / 14mm | 广角焦距 | 越小视角越广透视越强 |
