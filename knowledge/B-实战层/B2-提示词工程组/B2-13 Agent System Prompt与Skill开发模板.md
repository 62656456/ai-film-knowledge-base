### Skill 核心公式（直接复制）
> 来源：CSDN 博客自媒体，未独立核实·可信度低（其中"Coze官方Skill规范"归属已被证伪，模板中已改按 Anthropic Agent Skills 规范表述）

```
你是专业技能开发工程师，按 Anthropic Agent Skills 规范生成可直接部署的技能包。

【技能名称】：XXX
【核心目标】：一句话说明技能解决什么问题
【适用场景】：用户触发条件、使用人群
【输入要求】：用户输入格式、必填字段、示例
【执行流程】：Step-by-Step 执行步骤（必须清晰）
【输出格式】：结构化/Markdown/JSON/文件类型
【工具调用】：需要联网/文档/代码/插件等
【约束规则】：禁止行为、异常处理、安全要求
【交付物】：生成SKILL.md、scripts、资源包，符合 Agent Skills 目录规范
```

### Skill 标准目录结构（Anthropic Agent Skills 规范）
```
my-skill/
├── SKILL.md        # 必须：元数据 + 核心指令
├── scripts/        # 可选：可执行代码（Python、Shell等）
├── references/     # 可选：参考文档、规范、知识材料
└── assets/         # 可选：模板、图片、资源文件
```

三级渐进加载机制：
- Level 1（始终加载）：SKILL.md的name+description元数据，约100 Token
- Level 2（触发加载）：SKILL.md完整正文，建议控制在5000 Token以内
- Level 3（按需加载）：子文档、脚本、参考文件

### 最小可用 SKILL.md 完整示例（代码审查Skill）
> 来源：今日头条自媒体，未独立核实·可信度低（示例结构与 Anthropic Agent Skills 规范一致）

```markdown
---
name: code-reviewer
description: 对后端代码进行结构化 Code Review，重点检查安全风险、
  逻辑错误和可维护性问题。当用户要求 review 代码、检查代码质量、
  分析潜在 bug 时触发。
---

## 审查顺序
1. 先检查安全问题
2. 再检查逻辑正确性
3. 最后检查可维护性和可读性

## 必查项
### P0：安全问题
- SQL 拼接
- 密钥硬编码
- 未鉴权接口

### P1：逻辑问题
- 空指针风险
- 并发安全问题
- 边界条件缺失

### P2：质量问题
- 函数过长
- 重复逻辑
- 命名含混

## 输出格式
每个问题按以下格式输出：
- 严重级别
- 问题描述
- 原因
- 修改建议
```

### Coze 变量管理规范（⚠️ 待核：未经Coze官方文档核对）
- 变量必须用`{{}}`双大括号包裹：`{{user_name}}` 正确，`{{ user_name }}` 错误
- 变量名区分大小写
- 空值处理：`{{#if data}}有结果：{{data}}{{/if}}`
- 列表拼接：`{{db_query_list|list_join:"、"}}` 生成"北京、上海、深圳"

### 模型选择策略表（2026-08-03 口径）

> 时效说明：模型更替快，本表不再把型号和任务永久绑定；当前家族快照见 C2-12，执行时以当期在售模型和同题小样为准。

| 使用场景 | 推荐模型 | 理由 |
|---|---|---|
| 生成产品卖点等轻量文本 | 当期 mini / Flash / Haiku / 国产轻量档 | 先用 20 条真实样本测正确率、语气和延迟 |
| 创意文案 | 当期中高能力文本档 | 盲评语感、品牌约束和重复率，不按品牌预设冠军 |
| 生成视频分镜 | 支持长上下文、结构化输出与视觉输入的当期高能力档 | 还要验证人物、空间、道具和镜头连续性，不以文字漂亮代替可拍性 |
| 复杂数据分析 | 当期高推理档 + 可验证工具链 | 代码/计算结果必须回测，价格只是约束之一 |

## 四、提示词反写方法模板

### 反向推导Prompt（直接复制）
> 来源：今日头条自媒体，未独立核实·可信度低

把别人的AI生成作品丢给大模型，让它反推Prompt：
1. 拿到别人的AI生成作品（PPT、文章、图片等）
2. 把作品截图/内容丢给大模型
3. 让大模型推测生成该作品的指令
4. 拿到反推的Prompt后微调
5. 用该Prompt重新生成，对比效果验证

### 分析法反推Prompt
> 来源：今日头条自媒体，未独立核实·可信度低

```
[x]是什么？好的[x]有什么特点？
现在，请分析以下[x]的 [特点1]、[特点2]、[特点3]、[特点4]等特点，
给出可以生成这个[x]的 Prompt
```

### 原汤化原食法（AI生成Prompt）
```
把任务的简单描述丢给大模型，让它帮你生成一个完善的Prompt。你拿到后再进行简单微调，用这个"AI写给AI的指令"去生成内容，效果往往出奇得好。
```
