# 片段与镜头输出格式

> 用途：规定人直接阅读和确认的剪辑分镜格式。分镜只保留观众最终看见的镜头决策，不再显示内部工程字段。模型生成方式由当前 `ai-storyboard-director` Skill 另行判断。

## 一、核心结构

```text
片段
→ 非等分时间轴
→ 时间轴内的多个镜头
→ 按平台和复杂度编译模型生成片段
```

一个剪辑片段可以包含多个不同景别、时长、机位、动作和声音的镜头；这不等于要求视频模型在一次生成中自动完成全部切镜。剪辑镜头与模型生成片段必须分开处理。

## 二、正式分镜格式

```text
# <片段编号｜标题>
总时长：<N秒>
画幅：<16:9 / 9:16 / 2.39:1>

| 时间 | 景别 / 机位 | 摄影机 | 画面与动作 | 台词 / 声音 |
|---|---|---|---|---|
| 0–Xs | <景别、角度、焦段参考> | <固定/推进/跟拍等> | <观众实际看见的动作> | <原台词/声音> |
| X–Ys | ... | ... | ... | ... |
```

字段说明：

- **时间**：该镜头在视频片段中的起止时间。
- **景别 / 机位**：景别、角度及必要的焦段参考。
- **摄影机**：固定、推进、拉远、横移、跟拍、摇摄等实际运动。
- **画面与动作**：人物和物体真实发生的动作及结果。
- **台词 / 声音**：原台词、呼吸、动作音和环境音。

## 三、时间分配

禁止机械等分。

时间由以下条件决定：

- 动作完成所需物理时间；
- 台词按正常或指定情绪语速所需时间；
- 观众识别人物、空间和信息所需时间；
- 反应、停顿和动作结果所需时间。

7秒片段可以是：

```text
0–1.4s：远景或中远景
1.4–4.6s：中景或中近景
4.6–7.0s：近景或特写
```

这只是多镜头示意，不是固定模板。镜头数量和时长必须由当前事件决定。

## 四、不再进入正式分镜的内容

以下内容从人读分镜中删除：

- 怎么接上一镜；
- 与上一镜关系、过渡方式、剪辑动机；
- 首帧 / 中段 / 尾帧；
- SEG总账和关系链；
- `exec`；
- `entry.*`、`exit.*`、`anchors.*`；
- 翻车点 + 规避；
- 可改入口；
- 26项可见自检。

必要的覆盖、连续性和完整性检查只在内部完成，不得用长清单干扰用户阅读。

## 五、分镜与生成的接口

分镜表确认后，交给当前 `ai-storyboard-director` Skill：

- 零硬切、低复杂度连续镜头 → `LONG_TAKE`；
- 多机位、反打、跨镜状态、持物或精确对白 → `SHOT_PACKAGE`；
- 平台或模型版本未知 → `PLATFORM_PENDING`。

每个实际模型调用包必须独立包含该镜所需的人物与场景参考、空间、道具、光线、生成时长、开始与结束状态；不得依赖一份模型看不到的全局长说明。
