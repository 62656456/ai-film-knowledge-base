# 即梦运镜光影术语完整词库
> 用途（查术语）：15种景别+14种角度+20种运镜+18种组合+15种光线+15种构图术语速查

---

## 一、景别（15种）

| 景别 | 画面范围 | 适用场景 |
|------|---------|---------|
| 大全景 | 极广阔，人物占画面很小 | 开场交代环境、史诗场景 |
| 全景 | 完整展示人物全身+环境 | 人物出场、环境关系 |
| 中全景 | 人物膝盖以上 | 日常对话、行走 |
| 宽景 | 横向宽幅画面 | 城市天际线 |
| 中景 | 腰部以上 | 对话互动、叙事主体 |
| 中近景（即胸像镜） | 胸部以上 | 亲密对话、情感表达；肖像、证件照 |
| 近景 | 肩部以上 | 面部表情细节 |
| 特写 | 面部或物体局部 | 情绪放大、细节强调 |
| 大特写 | 眼睛/嘴唇/手等极小区域 | 极致情绪冲击 |
| 半身镜 | 半身 | 正式场景 |
| 全身镜 | 全身 | 服装展示、全身造型 |
| 环境全景 | 只展示环境不展示人物 | 场景切换、氛围建立 |
| 空镜 | 无人物的纯环境画面 | 转场、情绪渲染 |
| 远景 | 人物与环境的远距离关系 | 旅行、开阔场景 |
| 极远景 | 极远距离俯瞰 | 航拍、壮丽景观 |

## 五、运镜万能公式

```

```

## 八、电影感拉满组合

```
近景 + 低角度仰拍 + 侧逆光 + 浅景深 + 慢镜
```

五个要素叠加，几乎能保证任何场景都有电影质感。
