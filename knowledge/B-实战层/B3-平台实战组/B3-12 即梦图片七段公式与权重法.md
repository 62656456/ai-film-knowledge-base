# 即梦图片七段公式与权重法
> 用途（写图片提示词）：Seedream 5.0七段公式、括号权重法、五要素精简法
> ✅ Seedream 5.0 版本号已核实为真（2026-07-05）。⚠️ 括号行为：社区实测称即梦括号会弱化（官方手册未记载，且存在相反的 ()→[]→{} 三级加权说法），**以真实界面实测为准**；稳妥做法=不用括号，用自然语言前置/顿号并列/全角【】强调。

## 一、七段公式

适用于即梦Seedream 5.0等图片生成模型。每一层都有明确功能：主体锁定谁、场景锁定哪、风格锁定调性、光影锁定质感、镜头锁定视角、细节锁定精度、技术锁定规格。

```
主体描述 + 场景环境 + 风格取向 + 光影氛围 + 镜头语言 + 细节质量 + 技术参数
```

### 各段说明

| 段落 | 作用 | 示例 |
|------|------|------|
| 主体描述 | 锁定核心人物/物体的外貌特征 | 一位穿米白色亚麻长裙的年轻亚洲女性，短发微卷 |
| 场景环境 | 锁定画面发生的地点 | 清晨阳光洒落的日式杂货咖啡店窗边座位 |
| 风格取向 | 决定成片整体气质 | 电影感摄影，温暖的日系生活美学 |
| 光影氛围 | 质感捷径 | 晨光从左侧窗户斜射入室，逆光边缘柔和金色轮廓光 |
| 镜头语言 | 决定观看视角 | 中景构图，浅景深，前景有虚化绿植剪影 |
| 细节质量 | 苛求程度 | 皮肤质感真实、毛衣纹理清晰、光斑自然 |
| 技术参数 | 锁定输出规格 | 竖屏9:16，4K |

### 完整示例（可直接复制修改）

```
一位穿米白色亚麻长裙的年轻亚洲女性，短发微卷，双手捧着一杯还在冒热气的拿铁。
清晨阳光洒落的日式杂货咖啡店窗边座位，身后的木架上摆满陶器。
电影感摄影，温暖的日系生活美学。
晨光从左侧窗户斜射入室，逆光边缘呈现柔和的金色轮廓光。
中景构图，浅景深，前景有虚化的绿植剪影。
皮肤质感真实、毛衣纹理清晰、光斑自然。
竖屏9:16，4K。
```

## 二、强调权重法（⚠️括号行为存疑，以实测为准）

⚠️ **即梦括号加权行为无官方定论**：社区实测称括号 `（（（主体）））` 在即梦里会触发弱化过滤、降低优先级，层数越多主体越被削弱；但官方手册未记载括号行为，且社区同时流传相反的 ()→[]→{} 三级加权说法。两说冲突，**以你所用版本的真实界面实测为准**。

**稳妥做法：不用括号**，改用以下即梦确定有效的强调方式：

```
1. 自然语言前置——把核心主体放在提示词最开头（AI优先处理靠前内容）
2. 顿号并列——用顿号把关键特征平铺列出，如"橘猫、圆脸、琥珀色眼睛"
3. 破折号锚定——用破折号补充锁定关键细节，如"橘猫——毛色偏暖、有虎斑纹"
4. 全角【】强调核心特征——如【棕色卷发】【米白色亚麻长裙】
```

对照示例：

```
普通：一只猫坐在窗台上
稳妥强调：【橘猫】坐在雨天的窗台上——毛色偏暖、圆脸、琥珀色眼睛
（避免写：一只（（（橘猫）））坐在雨天的窗台上——括号行为存疑，未实测前不要依赖）
```

## 三、五要素精简法

如果觉得七段公式太复杂，用这套更精简的：

```
主体 → 背景 → 风格 → 色彩 → 氛围
```

| 要素 | 说明 | 示例 |
|------|------|------|
| 主体 | 核心人物/物体 | 一位穿汉服的年轻女子，手持团扇 |
| 背景 | 环境设定 | 苏州园林月洞门内，竹影斑驳，石阶微湿 |
| 风格 | 视觉类型 | 工笔水墨风格 / 写实摄影风格 |
| 色彩 | 色调和光影 | 低饱和莫兰迪灰调 / 青橙对比色 |
| 氛围 | 情绪注入 | 静谧孤独感 / 节日欢庆氛围 |

## 四、新手三个常见坑

1. **提示词太长太乱**：结构清晰比字数多重要得多
2. **重要元素放末尾**：AI优先处理靠前的内容，核心主体放最开头
3. **只靠单次不迭代**：出图不满意不是放弃，而是优化提示词迭代
