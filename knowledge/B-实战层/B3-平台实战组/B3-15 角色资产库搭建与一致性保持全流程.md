## 四、固定种子+角色描述模板法

> 来源：https://www.php.cn/faq/1534679.html （来源：自媒体，未独立核实）

操作步骤：
1. 在生成第一张角色图像时记录所使用的种子数值。
2. 在后续生成同一角色的其他图像时，手动输入相同的种子值。
3. 保持主要提示词不变，仅调整场景或动作描述以适应新的构图需求。

结构化角色描述格式：
```
'[角色名]，18岁女性，黑长直发，棕色眼睛，瓜子脸，常穿红色风衣'
```

ControlNet + IPAdapter 权重配置：
```
选择一张已确认的角色正脸图为参考图。启用ControlNet插件并上传参考图，设置模式为'IP-Adapter'或'Reference Only'。调整权重参数（通常0.6~0.9），平衡参考图影响与创意自由度。
配合边缘检测或骨骼图可进一步锁定姿势与轮廓一致性。
```

## 五、IPAdapter 参数速查

> 来源：https://blog.csdn.net/2401_84760527/article/details/144804757 （来源：自媒体，未独立核实）

权重设置：
- 权重 0.1：参考图影响极弱
- 权重 0.5：适度参考
- 权重 1.0：标准
- 权重 1.5+：开始过拟合，逐渐变成坏图

权重类型选用：
- **Linear（线性）**：始终均匀影响
- **Ease Out（缓出）**：开始强后减弱——想参考原图又想受提示词影响选这个
- **Weak Input（弱输入）**：减少处理链开始时影响
- **Weak Output（弱输出）**：减少处理链末端影响
- **Strong Middle（强中间）**：放大中心部分效果

## 十、去AI味——物理渲染拟真四阶流

> 来源：http://m.toutiao.com/group/7648455441186128390/ （来源：自媒体，未独立核实）

你的角色是**专业人像摄影师**，而非指令输入者。遵循'**场景定义 → 光学物理 → 瑕疵保留 → 氛围营造**'的四阶创作流：

### 1. 叙事性场景锚定
不要定义"她是美的"，而是定义"她在哪里，在做什么"。强制加入叙事元素，如"清晨窗台边的作家，手边放着喝了一半的美式咖啡"。

### 2. 精密的光学控制关键词
必须包含**胶片颗粒（film grain）**、**浅景深（shallow depth of field）**、以及特定焦段如**85mm镜头（85mm lens）**。使用**伦勃朗布光（Rembrandt lighting）**或**自然侧光（natural window light side lighting）**制造面部高对比度阴影。

### 3. 非破坏性"瑕疵"保留
正向指令："可见的皮肤纹理（visible skin texture）"、"真实的毛孔（realistic pores）"、"阳光下细微的绒毛（peach fuzz in the sunlight）"

反向钳制："过度平滑（overly smooth）"、"塑料质感（plastic skin）"、"焦糖滤镜（instagram filter）"、"液化效果（liquefied effect）"

### 4. 化学/物理反应模拟
```
金黄色的阳光洒在汗湿的皮肤上，产生微弱的油膜反光（golden sunlight glistening on slightly sweaty skin）
```
色彩科学："基于Agfa Vista胶片的色彩科学（Agfa Vista film color science）"
