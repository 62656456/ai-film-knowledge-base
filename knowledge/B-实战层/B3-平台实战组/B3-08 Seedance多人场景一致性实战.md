# Seedance多人场景一致性实战
> 用途（做多人视频）：多人空间锁定、正反打主次区分、肢体接触规避、递进式分批生成、音频锚点

---

## 一、锁定空间位置

多人画面最大隐患不是人物样貌变形，而是**站位、视线朝向**失控。

逐镜标注位置，摒弃模糊描述：

- 错误：一男一女坐在咖啡馆交谈
- 正确：男生位于画面左侧，女生位于画面右侧，二人面对面就坐，男生身形略高，彼此目光相对

**遵循影视180度轴线规则**：左侧人物始终望向右侧，右侧人物始终望向左侧，固定人物视角。

## 二、划分主次焦点

AI模型很难同时均衡处理两个同等重要的人物。每个镜头设定核心焦点人物：

- 镜头一：角色A为视觉焦点，角色B置于画面边缘并虚化
- 镜头二：切换焦点至角色B，角色A弱化作为背景
- 全景镜头：保留双人画面，焦点人物略微靠前占视觉主导

用景别区分主次：焦点人物用近景/中近景，次要人物用中景/远景。

**推荐**：极少使用标准双人同景镜头，大多采用单人镜头交替剪辑（正反打），最后用全景收尾。

## 三、弱化肢体接触

拥抱、握手、对视等画面极易穿模、肢体变形、五官融合。核心思路：**不直接拍摄接触画面，用镜头暗示互动关系（留白手法）。**

| 原画面 | 优化方案 |
|--------|---------|
| 两人拥抱 | 一人抬手迈步停在接触前瞬间；下一切镜切换至远景通过轮廓体现相拥状态 |
| 两人握手 | 特写两只手缓缓靠近，不产生接触，随即切换镜头 |
| 亲密对视亲吻 | 面部慢慢靠拢，画面模糊处理后转场 |

## 四、递进式分批生成法

多人同框一次性生成是新手最易踩的坑。以三名角色A、B、C为例：

1. 第一阶段：仅生成A、B同框镜头，反复调试彻底固定两人特征
2. 第二阶段：制作B、C同框画面，以已定型的B为参照校准C
3. 第三阶段：搭配A、C出镜，依靠两个成熟角色互相参照保持统一
4. 第四阶段：最后制作三人同框镜头，此时所有人物形象均已锁定

核心：逐步降低模型运算压力，每步只新增一个变量。

## 五、声音锚点（音画同步）

| 要点 | 方法 |
|------|------|
| 区分声纹音色 | 为不同角色搭配差异化配音，同性人物也要区分音色高低、声线粗细 |
| 匹配立体声声场 | 画面左侧人物声音偏左声道，右侧人物声音偏右声道 |
| 统一环境音效 | 同一场景全程保持环境音一致，避免镜头切换后突然出现/丢失背景音 |
| 补充细节音效 | 适当添加呼吸声、衣物摩擦声、细微动作音效 |
