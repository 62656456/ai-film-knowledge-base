## 一、完整制作流程六阶段

### 阶段1：创意构思

**目标**：明确视频主题、受众和视觉风格。

执行清单：
- 确定视频用途（品牌广告、产品展示、叙事短片、社交媒体内容）
- 锁定视觉风格方向（写实/动画/插画/混合）
- 搜集3-5个对标参考作品，截图标注关键画面
- 撰写200字以内的创意简报，包含：一句话梗概、目标情绪、核心画面描述

### 阶段2：分镜设计

**目标**：将创意拆解为可执行的镜头序列。

分镜脚本模板：
```
镜头编号 | 时长 | 画面描述（中文） | 运镜方式 | 角色动作 | 场景环境 | 生成模式
L01      | 3s   | 女主角走在雨中街道 | 缓慢推进 | 行走、转身回眸 | 霓虹灯城市 | 文生视频
L02      | 4s   | 特写：雨滴落在手心   | 固定微距 | 手掌托起     | 虚化背景   | 图生视频
L03      | 2s   | 全景：城市天际线     | 航拍上升 | 无           | 黄昏天空   | 文生视频
```

关键规则：
- 单镜头时长建议2-5秒，叙事镜头不超过5秒
- 每个镜头必须明确运镜方式和角色动作
- 相邻镜头之间考虑转场衔接（运动方向连贯、色调统一）

### 阶段3：资产准备

**目标**：建立可复用的角色、场景、道具素材库。

详见本文"资产库建设"章节。

### 阶段4：提示词编写

**目标**：为每个分镜编写精准的英文提示词。

编写流程：
1. 用中文写出完整的画面描述（含主体、动作、环境、光影、情绪）
2. 将描述翻译为英文，补充技术参数术语
3. 按照八段式骨架排列提示词（详见 B3-05《即梦提示词写法完全手册》）
4. 添加运镜指令和动态控制参数
5. 检查负面约束（写入主提示词约束段）

### 阶段5：批量生成与筛选

**目标**：高效生成多个候选版本，筛选最优结果。

操作规程：
- 每个分镜至少生成4个版本，调整不同参数组合
- 优先使用图生视频模式（可控性更高）
- 生成后立即标记：A/B/C/D评级，记录使用的参数
- 保留所有候选素材，不要删除（后续可组合使用）

筛选标准：
| 维度 | 权重 | 说明 |
|------|------|------|
| 画面质量 | 30% | 清晰度、细节丰富度、无伪影 |
| 动作合理性 | 25% | 人物动作自然、物理规律正确 |
| 风格统一性 | 20% | 与前后镜头风格一致 |
| 情绪表达 | 15% | 是否传达目标情绪 |
| 技术参数 | 10% | 运镜幅度/速度是否合适、首尾帧是否稳定、运镜是否流畅 |

### 阶段6：后期处理与输出

**目标**：统一调色、音频合成、输出成片。

后期流程：
1. 导出所有镜头素材（最高质量）
2. 在剪辑软件中排列时间线
3. 镜头间添加转场（建议：硬切70%、叠化20%、其他10%）
4. 统一调色（推荐LUT：Kodak 2383 / Arri Look Library）
5. 添加BGM和音效
6. 导出最终成片

## 二、资产库建设

### 2.1 角色一致性管理

核心问题：AIGC视频最难点是保持同一角色在不同镜头中的一致性。

解决方案：

**方案A：角色参考图法**
- 使用MidJourney或即梦图生图生成高质量角色定妆照
- 固定参数：同一Seed值、相同描述词中的角色部分
- 保存至少3张不同角度的角色参考图（正面、侧面、背面）

角色档案卡模板：
```
角色名称：都市女主角
参考图路径：/资产库/角色/主角/
关键词组合：
A young East Asian woman, 26 years old, shoulder-length wavy black hair,
almond eyes, natural makeup, slim figure, wearing a beige trench coat
固定参数：Seed固定值, style_reference参数启用
```

**方案B：即梦角色一致性功能**
- 在即梦平台中使用"角色一致性"功能
- 上传角色参考图后，系统自动提取面部特征
- 后续生成时引用该角色ID，保持面部一致
- 注意：服装和发型仍需在提示词中指定

**方案C：Seed锁定法**
- 找到一个满意的角色生成结果
- 记录该结果的Seed值
- 后续生成时使用相同Seed + 微调场景描述
- 适用场景：同一场景内多角度拍摄

### 2.2 场景资产管理

场景资产分类：
```
/资产库/
  /场景/
    /都市/
      霓虹街道_夜晚_v1.png
      咖啡厅内景_白天.png
      天台_黄昏.png
    /自然/
      森林小径_晨雾.png
      海边悬崖_日落.png
    /室内/
      工作室_简洁风.png
      卧室_暖光.png
  /道具/
    手机_正面.png
    咖啡杯_特写.png
  /氛围/
    雨效果素材.mp4
    粒子光效.mp4
```

场景资产建设规则：
- 每个场景提供至少1张参考图 + 对应的提示词记录
- 场景图要求：分辨率1920x1080以上，无文字水印
- 场景描述词模板需包含：环境类型、时间段、天气、色调、构图

### 2.3 道具资产管理

道具资产制作方法：
- 简单道具：直接文生图生成，使用 `isolated on white background, product photography style`
- 复杂道具：用即梦图生图功能，上传草图或参考图
- 特定品牌道具：上传真实照片，用图生图保持外观一致性

道具资产命名规范：
`道具名_角度_光照条件_版本号.扩展名`

## 三、图生视频 / 图生图最佳实践

### 3.1 图生视频（Image-to-Video）

**最佳输入图片要求**：
- 分辨率：1280x720 或 1920x1080
- 构图：主体居中偏左/右（留出运镜空间），避免满画面构图
- 内容：图片中已有明确的运动趋势（人物朝向、视线方向）
- 风格：与目标视频风格完全一致

**推荐参数配置**（即梦视频真实可调项，无 dynamic_focus 等伪参数）：
```
生成模式：图生视频
运镜方向：上/下/左/右/旋转/变焦（按需选）
运镜幅度：三档（小/中/大）
镜头速度：慢/正常/快
首尾帧权重：优化 / 超强优化
时长：4-15 秒可选
分辨率 / 画幅比例：按平台需求（16:9 / 9:16 / 1:1）
```

**图生视频提示词结构**：
```
[主体动作描述], [运镜方式], [环境光影变化], motion smooth, cinematic
```

示例：
```
A young woman slowly turns her head and smiles gently, slow push-in camera,
soft golden hour lighting gradually intensifies, motion smooth, cinematic 4K
```

### 3.2 图生图（Image-to-Image）

**核心用途**：
- 场景变体生成（同一场景不同时间段）
- 角色换装（保持面部长相不变）
- 风格迁移（写实转插画等）

**最佳实践**：
- 参考图权重设置0.6-0.8（过高则变化太小，过低则失去参考）
- 提示词中明确指出需要保留和需要改变的部分
- 用于角色一致性时：保留面部描述，改变环境和服装描述

## 四、2.5素材驱动方法

### 4.1 什么是2.5D素材驱动

2.5D素材驱动是一种混合工作流：使用2.5D风格素材（介于平面与3D之间的立体感素材）作为输入，结合即梦的视频生成能力，快速产出高质量视频。

适用场景：
- 品牌宣传视频（需要统一视觉体系）
- 产品展示视频（需要精确的产品表现）
- 社交媒体批量内容生产

### 4.2 2.5D素材准备

**来源渠道**：
- 3D渲染软件输出（Blender/C4D渲染的等角视角场景）
- 即梦/Seedance自身生成的2.5D风格图片
- 购买的2.5D插画素材包
- 3D资产网站（Sketchfab、TurboSquid）

**素材要求**：
- 等角视角（isometric）或微透视角度
- 统一的色彩体系和光照方向
- PNG格式，背景透明
- 分层交付（背景层、主体层、前景层分开）

### 4.3 2.5D素材驱动生成流程

```
Step 1: 在Blender/C4D中渲染2.5D场景关键帧
Step 2: 导出为PNG序列（保持透明通道）
Step 3: 在即梦中使用图生视频模式
Step 4: 提示词强调2.5D风格：
        isometric 3D style, soft studio lighting, clay render,
        pastel color palette, smooth camera orbit
Step 5: 批量生成不同角度和运镜的版本
Step 6: 后期合成（叠加文字动画、粒子效果）
```

**效率提升数据**（来源文章声明，无独立验证）：
- 纯文生视频：平均每镜头需生成8-12次才能满意
- 2.5D素材驱动：平均每镜头只需生成3-5次
- 整体制作效率提升约60%

## 五、优秀作品参数参考

### 5.1 即梦视频真实可调项

即梦视频界面并没有"动态焦点"这类数值滑杆。真实可调项如下（原 dynamic_focus 72%-85% 系编造，已删）：

- **运镜方向**：上 / 下 / 左 / 右 / 旋转 / 变焦
- **运镜幅度**：三档（小 / 中 / 大）
- **镜头速度**：慢 / 正常 / 快
- **首尾帧权重**：优化 / 超强优化
- **时长**：4-15 秒可选
- **分辨率 / 画幅比例**：按平台需求选择

**核心经验**：想要细腻的近景微表情就选小幅度运镜+慢速；动作场景选大幅度运镜；风景/产品选缓慢的旋转或变焦。不存在"焦点百分比"这一参数。

### 5.2 LUT调色参考

**推荐LUT方案**：

| 风格 | LUT名称 | 适用场景 | 色调特征 |
|------|---------|----------|----------|
| 电影感 | Kodak 2383 | 叙事短片、品牌片 | 暖色偏移，高光偏橙，暗部偏绿 |
| 广告质感 | Arri Look Library | 商业广告 | 中性偏暖，肤色还原优秀 |
| 日系清新 | Fuji Eterna 250D | 生活方式、Vlog | 低对比度，青绿色调，柔和 |
| 赛博朋克 | Teal & Orange | 都市、科技主题 | 高对比度，蓝橙互补色 |
| 复古胶片 | Kodak Vision3 500T | 回忆叙事、文艺片 | 颗粒感，暖色偏移，柔和高光 |

### 5.3 风格取向

即梦无 style_strength 数值参数（原数值系编造）。风格通过提示词中的自然语言描述控制（如"写实摄影""日系插画""电影质感"），并可搭配全能参考上传风格参考图。

### 5.4 其他真实关键参数

```
画面比例：
  横屏（16:9）：适合叙事短片、品牌片、BGM视频
  竖屏（9:16）：适合抖音、小红书、Reels
  方形（1:1）：适合Instagram帖子

生成时长：
  4-15 秒可选（短时长质量最稳定；时长越长运动一致性越难保持）

运镜幅度：三档（小 / 中 / 大），配合镜头速度（慢 / 正常 / 快）
  ——即梦无 camera_motion_intensity 数值参数（原数值系编造）
```

## 六、Seedance 2.0新特性

### 6.1 核心升级

Seedance 2.0（2026-02-07 发布）是即梦平台的视频生成模型，相比前代有显著提升。

> 口径说明：官方公开信息仅确认 **2K 分辨率、生成速度提升约30%、多模态输入** 三项。下列条目中超出此范围的具体数字，均为厂商宣称·未独立复核。

**分辨率升级**
- 支持2048x1152（2K）原生输出
- 文生视频直接生成1080p
- 放大倍率提升（"可至4倍（配合超分）"为厂商宣称·未独立复核）

**运动一致性改进**
- 人物运动更符合物理规律
- 多人物场景中各角色运动独立
- 手部和面部细节改善（"手指融合问题减少80%"为厂商宣称·未独立复核）

**新运镜指令**
- 支持复合运镜：`dolly in + tilt up`（推进+上摇）
- 支持速度曲线：`slow to fast` / `ease in ease out`
- 支持目标追踪：`tracking shot following the subject`

**角色一致性增强**
- 支持多角色同时保持一致性
- 角色参考图数量上限（"5张"为厂商宣称·未独立复核；全能参考素材上限规格正本见 B3-09）
- 跨镜头服装一致性保持能力提升

### 6.2 即梦视频真实可调项（无"专属参数"代码）

即梦界面没有 character_consistency / motion_physics_enhance / texture_detail_level / dynamic_focus / camera_motion_intensity / style_strength 这类可填参数（均系编造，已删）。真实可调项只有：

```
运镜方向：上/下/左/右/旋转/变焦
运镜幅度：三档（小/中/大）
镜头速度：慢/正常/快
首尾帧权重：优化 / 超强优化
时长：4-15 秒
分辨率 / 画幅比例：按需
```

角色一致性靠**全能参考上传角色图**（@图片N 引用）+ 自然语言描述实现，不是勾选参数开关。

### 6.3 Seedance 2.0使用注意事项

- 首次尝试新运镜组合时建议先用短提示词测试效果
- 时长越长，运动一致性越难保持，复杂动作优先控制在短时长
- 角色一致性对正面角度效果最好，大侧面和背面仍有偏差
