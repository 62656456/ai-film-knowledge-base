# Seedance @语法与多模态参考指南
> 用途（用多模态功能）：首尾帧模式、全能参考模式、@语法7种用法、人物一致性方法、音乐卡点
> ✅ 已核实（2026-07-05/07-09）：@图片N/@视频N/@音频N 语法与"图≤9/视≤3/音≤3/总≤12、4-15秒"规格均已官方文档级核实；9图=满血版口径，Seedance 2.0 Mini 为 6 图。唯一待实测=真实上传界面逐项数字。

---

## 一、两种入口模式

### 首尾帧模式（新手）
- 输入：一张首帧/尾帧图 + 文字提示词
- 典型用法：用当前剪辑镜头的9:16首帧约束一个连续生成片段；平台支持并已实测时再加尾帧
- 适合：单镜动作、逐镜生成和首尾状态控制

### 全能参考模式（进阶）
- 输入：图片（≤9张）+ 视频（≤3段）+ 音频（≤3段）+ 文本
- 注：9图=满血版口径；Seedance 2.0 Mini 上限为 6 图
- 单次总计 ≤12 个文件，素材总时长 ≤15s，生成时长 4-15 秒可选
- 解锁：精准复刻运镜/动作/氛围、视频延长、场景补全、音乐卡点

## 二、@语法核心用法

素材引用按**上传类型+序号**指定：`@图片N`（第N张上传图）、`@视频N`（第N段上传视频）、`@音频N`（第N段上传音频）。这是即梦真实的引用方式——不是自定义角色名，模型不会自动猜测素材用途，必须用@明确指定：

| 用途 | 示例 |
|------|------|
| 指定首帧 | @图片1 作为首帧，定下整体画风 |
| 参考运镜 | 参考@视频1的运镜方式，从全景推到特写 |
| 指定角色 | @图片1 中的女生作为主角（按上传序号引用该角色图，非角色名） |
| 融合多视频 | 在@视频1和@视频2之间加一个场景转换 |
| 延长视频 | 将@视频1延长5秒 |
| 声音参考 | @音频1 作为配乐，对齐画面节奏 |
| 负向提示 | 无文字叠加，无水印 |

## 三、多人物一致性进阶方法

1. 第一次生成 → 保存最满意的镜头截图
2. 第二次生成 → 将截图作为@参考图上传
3. 把截图上传为图片1，提示词中明确：`@图片1中的女生作为主角，保持服装和脸部一致`

## 四、音乐卡点技巧

上传音乐文件后，在提示词中加入：

```
@音频1 中 X秒处的鼓点，同步主角的转身动作
```

模型会自动对齐画面与音乐节奏。

## 五、逐镜衔接方法

平台支持多素材与时间提示，不等于模型能在一次生成中稳定记住多次硬切后的空间和道具状态。

有反打、人物移动、持物、开合、交接或精确对白时：

1. 每个剪辑镜头先做目标画幅首帧；
2. 当前镜头只绑定实际需要的人物、场景、首帧或音频素材；
3. 一次调用只生成一个连续镜头；
4. 上一镜审核通过的结束帧可作为下一镜首帧或状态参考；
5. 硬切、J-cut、L-cut和准确时码由后期完成。

多镜头一条提示词只可作为用户明确接受随机漂移的快速探索，不得作为需要空间、道具和对白连续性的正式生产方案。

## 六、实战案例：品牌广告

上传映射：图片1=产品照片；视频1=运镜参考；音频1=15秒背景音乐。

提示词：
```
将@图片1中的产品放在画面中央，参考@视频1的旋转跟随方式，
从俯拍推进到侧面特写，营造高级感。@音频1同步卡点，
画面配色为冷色调，电影级色彩分级。
```
