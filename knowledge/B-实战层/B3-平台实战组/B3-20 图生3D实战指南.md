## 二、Tripo提示词公式

> 来源：http://m.toutiao.com/group/7618089930513826339/ （自媒体软文，未独立核实）

```
[主体描述] + [风格修饰] + [材质细节] + [技术规格]
```

示例：
```
赛博朋克机械义肢手臂，镀铬和哑光黑色表面处理，
外露的液压活塞和线路，霓虹蓝色LED装饰，
磨损的战斗损伤纹理，高科技军用级设计，
无缝关节连接，细致的面板线条，
PBR材质，游戏可用拓扑结构，4K纹理分辨率
```

图像转3D最佳实践：
1. 分辨率建议1024x1024或更高，背景纯色最佳
2. 多视图上传（正面、侧面、背面三视图）效果最佳
3. 生成后用"部件拆分"自动识别逻辑部件

完整流程：概念生成（即梦/Midjourney）→ Tripo快速建模 → Meshy拓扑优化 → Luma材质参考（可选）→ Blender精修 → 导出FBX/GLB

## 三、Tripo API Python批量生成代码模板

> 来源：http://m.toutiao.com/group/7625662886735544882/ （自媒体软文，未独立核实）
> 注：Tripo 官方 Python SDK 名为 `tripo3d`（真实存在），可 pip 安装批量调用（下方代码中的 `from tripo3d import ...` 即为此库）。

```python
import asyncio
from pathlib import Path
from tripo3d import TripoClient, TaskStatus

async def generate_scene_from_concept():
    async with TripoClient() as client:
        # 阶段1：检查余额
        balance = await client.get_balance()
        
        # 阶段2：Image-to-3D生成
        concept_image = "cyberpunk_building.jpg"
        task_id = await client.image_to_model(image=concept_image)
        
        # 阶段3：等待生成完成
        task = await client.wait_for_task(task_id, verbose=True)
        
        # 阶段4：下载模型文件
        output_dir = Path("./game_assets")
        output_dir.mkdir(exist_ok=True)
        downloaded_files = await client.download_task_models(task, str(output_dir))

asyncio.run(generate_scene_from_concept())
```
