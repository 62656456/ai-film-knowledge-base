## 7步标准制作流程（执行检查清单）

> 来源：http://m.toutiao.com/group/7645287619600892422/ （来源：自媒体，未独立核实）

### 第一步：写好剧本（一部漫剧的灵魂）
爆款漫剧剧本只有三个标准：
1. 开头3秒强钩子：冲突、反转、悬念、误会，必须立刻抓住人。
2. 单集剧情干净利落：10-20秒一个小剧情，每一集都有悬念收尾。
3. 台词简短口语化：短句、易懂、情绪足，避免大段旁白。

### 第二步：画分镜（解决画面混乱、镜头乱跳）
专业漫剧分镜只做三件事：
- 确定每一秒镜头景别（近景/中景/特写）
- 确定人物动作、表情、站位
- 确定场景、光线、氛围

### 第三步：AI生图（统一画风、统一人物、统一质感）
正确SOP：
1. 先做角色说明书/人设板锁定五官、发型、穿搭、肤色
2. 统一提示词风格、统一光影、统一色调
3. 所有镜头保持9:16竖屏
4. 每帧画面精细干净，无畸形、无变形

### 第四步：AI生视频（动态丝滑、不卡顿、不跳帧）
生视频重点：动作小、幅度稳、不做大跳跃、大转头；运镜缓慢、丝滑、轻微推拉；保持人物全程不变脸、不漂移；24-30帧流畅输出。

### 第五步：专业配音（决定代入感）
爆款漫剧配音标准：情绪匹配剧情（甜、怒、委屈、冷漠）；语速适中、停顿自然；多人对话音色区分明显；搭配轻微环境音、氛围音。

### 第六步：精剪成片（节奏决定流量）
爆款剪辑SOP：卡点剪辑、台词卡准画面；多余空镜全部删除；每3-5秒一个小转折；配乐轻柔不压人声；字幕清晰、字体统一、无遮挡。

### 第七步：标准化发布（决定能不能爆）
合规备案（避免下架限流）；标题带悬念钩子；封面高清抓人；话题精准垂直；定时稳定更新、连载不断更。

## 6步工业化量产流程（含固定指令模板）

> 来源：http://m.toutiao.com/group/7657149156447879734/ （来源：自媒体，未独立核实）

### 第一步：定题材+写工程化剧本
万能剧本指令（直接复制）：
```
帮我写一集60秒竖屏AI短剧剧本，甜宠/悬疑/古风（自选）。结构：开头3秒强钩子、中段冲突反转、结尾留悬念可追更。包含：人物设定、场景描述、每句台词情绪、镜头动作标注。一集8个镜头以内，语言口语化、节奏快、适合AI成片。
```

重点细节：不要写长剧情！单集6-8镜、50-70秒是平台最吃流量的黄金时长（经验参考·自媒体来源未独立核实）。一定要让AI标注：情绪、动作、场景光线、人物状态。

### 第二步：锁定固定人设+场景
固定人设指令：
```
生成高清真人女主，20岁，温柔清冷氛围感，淡妆，黑长直，日常穿搭，自然光，高清4K，正面标准人像，无变形，无滤镜浮夸。
```
核心原则：整部剧，一个人设图用到尾、一个场景风格用到尾。不要每镜重新生成，必崩。

### 第三步：标准化分镜拆解
黄金分镜模板：
```
1镜全景交代场景、2镜中景人物动作、3镜近景对话、4镜情绪特写、5镜细节补镜、6-8镜收尾悬念。
```

分镜万能指令：
```
把以上剧本生成8镜竖屏短剧分镜表格，9:16。统一人物颜值穿搭，统一场景色调。运镜：慢推、轻微跟随、轻摇，拒绝抖动。每一镜标注情绪氛围，镜头衔接流畅，无跳戏。
```

### 第四步：批量生成连贯视频画面
1. 每一镜单独生成，不要一镜到底长视频（容易崩坏）
2. 生成时强制上传人设参考图，勾选"保持人物一致"
3. 运镜全部选轻微动态：慢推、微摇、轻微跟随
4. 画质统一：4K、高清、电影质感、无畸形、无扭曲

### 第五步：专业级音频制作
人声100%、音效40%、BGM25%——被称为短剧黄金音量配比（经验参考·自媒体来源未独立核实）。

### 第六步：剪辑合成+包装成片
镜头转场统一：全部用叠化0.3秒（经验参考·自媒体来源未独立核实）；字幕设置：黑体、居中、大字、高对比度；统一滤镜全程一个。

## 5个生产级Prompt模板（智能体对接用）

> 来源：http://m.toutiao.com/group/7615084086629892651/ （来源：自媒体，未独立核实）

### 模板1：技术漫剧脚本生成
```
你是资深技术科普编剧+漫剧内容专家，擅长用通俗话术讲解后端开发知识，严格遵守以下规则生成内容：
1. 基础要求：生成3分钟内的短漫剧脚本，适配短视频/公众号配图，语言口语化、无晦涩术语，逻辑清晰
2. 技术底线：严禁虚构技术概念、严禁写错代码逻辑、严禁误导开发者，所有知识点符合Java/SpringBoot/后端开发常识
3. 内容结构：固定包含【场景描述+角色对话+核心知识点标注】三部分，角色固定为2个（技术小哥：主讲，小萌新：提问）
4. 输出要求：纯文本结构化输出，不要多余表情、不要markdown、不要无关解释，方便后端智能体解析
5. 用户需求：{userPrompt}
```

### 模板2：分镜智能拆解
```
你是专业漫剧分镜师，基于以下技术脚本，拆分为逐镜分镜内容，严格遵守规则：
1. 单条分镜时长：15-20秒，总时长不超过3分钟，对应脚本内容逐句匹配
2. 分镜格式：固定为【镜号+画面描述+台词+配音语气】，每镜单独一行，无多余格式
3. 画风约束：统一为简约科技风漫剧，背景为浅蓝代码风，角色形象固定，无夸张画风
4. 技术适配：画面中出现代码/架构图时，标注清晰，符合后端视觉习惯，不杂乱
5. 待拆解脚本：{scriptContent}
```

### 模板3：角色画风约束
```
强制约束以下漫剧生成规则，严禁修改：
1. 角色形象：技术小哥（黑发、戴黑框眼镜、穿休闲工装，沉稳专业），小萌新（短发、活泼，提问视角）
2. 整体画风：简约扁平科技漫剧，无复杂背景、无炫技特效，色调以蓝白灰为主，适配技术科普调性
3. 画面要求：文字清晰、重点知识点高亮，无错别字、无乱码，代码片段排版整齐
4. 禁止项：严禁改变角色形象、严禁切换画风、严禁添加无关娱乐元素
```

### 模板4：AI生成报错修复
```
检测到当前生成内容存在【技术错误/格式错误/画风不符】问题，请按照以下要求修复：
1. 修正所有技术知识点错误，确保符合后端开发常识
2. 统一格式为指定的分镜/脚本结构，方便智能体解析
3. 修复角色画风问题，保持形象统一
4. 修复后直接输出正确内容，不要多余解释
5. 待修复内容：{errorContent}
```

### 模板5：极简版快速生成
```
生成3分钟技术漫剧，主题：{userPrompt}，角色固定为技术小哥+小萌新，简约科技风，输出结构化脚本+分镜，技术严谨无错误，适配后端智能体解析
```

### 运镜镜头模板
- **贝式英雄镜头（Bayhem Shot）**：镜头以主角为中心缓慢旋转上升，角色保持向前走，周围环境向外扩散，专门用来烘托主角气场。
- **FPV微距镜头**：模拟无人机第一人称视角高速穿越场景，速度感和沉浸感直接拉满。
- **荷兰角**：倾斜机位，天然带压迫感，体现俯视和压制感。

提示词技巧：Seedance2.0对虚词难以理解（如"欢迎""生气""害羞"），要改成有具体表情和动作的描述，如把"欢迎"改成"手举过头顶挥3次放下"。

## 新手避坑铁律

> 来源：http://m.toutiao.com/group/7657149156447879734/ （来源：自媒体，未独立核实）

1. 先人设、再场景、最后画面，顺序不能乱。
2. 单集不超8个镜头，镜头越多越乱。
3. 全程动态轻微，拒绝大幅度动作。
4. 音色固定，多人绝不串音。
5. BGM音量永远小于人声。
6. 每集必须有钩子、反转、悬念。
7. 所有素材用官方合规生成，避免限流下架。
