## 公共工作流

```text
冻结输入与权限
  → 产出可判断的结果
  → 按交付物选择审核门
  → 失败：定位最早断裂点并定向退回
  → 通过：记录匹配交付物的证据
  → 标记真实状态
  → 需要公开时再过版权、隐私和来源门
```

## 三条底线

1. 文件存在、结构完整或自动检查通过，只能证明相应层级，不能替代内容、视觉、运行或用户验收。
2. 退回必须指向最早失效的决定，并保留已确认的约束；禁止把“全部重做”或“再生成一次”当默认修复。
3. 公共知识只保留可复用方法和公开证据。个人信息、个人项目、私人复盘、原始对话、内部路径和权利不明图片不因“有价值”而自动公开。

## 与 A / B 层的关系

- **A·理论层**回答为什么成立、如何判断。
- **B·实战层**回答怎样生产、怎样操作。
- **C·审核与验收层**回答何时退回、怎样审核、什么证据才算通过。

三层可以串成完整系统，也可以只打开一张卡单独使用。
